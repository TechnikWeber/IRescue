IRescue — Web Flasher

ESP32 direkt aus dem Browser flashen. Keine IDE, keine Installation.

  1. ESP32 DevKit-C per USB-Datenkabel anstecken.
  2. Browser: Chrome oder Edge am Desktop (Web Serial).
  3. Auf „Connect“ klicken, den seriellen Port des ESP32 wählen, „Install“.
Dieser Browser kann kein Web Serial — bitte Chrome/Edge am Desktop. Web Serial ist nicht erlaubt (nur über HTTPS).

Klemmt es beim Verbinden? Beim Klick auf „Install“ die BOOT-Taste am ESP32 gedrückt halten (manche Boards brauchen das).

Nach dem Flashen: mit dem offenen WLAN IRescue-XXXX verbinden — die Oberfläche öffnet sich automatisch (Captive Portal). Sonst http://192.168.4.1/ aufrufen.

Lieber selbst kompilieren oder ohne Browser flashen? Siehe Repository und docs/FLASHING.md.
